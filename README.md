# PSTORE2 — Loja de Jogos e Apps para PlayStation 2

**PSTORE2** é uma solução open-source para PlayStation 2 que permite baixar e instalar jogos e aplicativos homebrew diretamente pelo console — sem precisar tirar o pendrive ou HD da máquina toda vez que quiser adicionar algo novo.

## 🚀 Sobre o Projeto

O PSTORE2 nasceu para simplificar a vida de quem usa **OPL (Open PS2 Loader)**: em vez de transferir arquivos manualmente pelo PC, você navega, escolhe e baixa direto do próprio console, com uma interface pensada para ser rápida e intuitiva mesmo no controle.

---

## ⚙️ Requisitos

Antes de instalar, confira se o seu console atende a estes pontos:

- **Desbloqueio**: o PS2 precisa ter algum tipo de desbloqueio capaz de executar arquivos `.elf`.
- **Rede**: cabo Ethernet conectado ao console é obrigatório — o app depende de conexão com a internet para baixar os arquivos.
- **Armazenamento**: um pendrive ou HD formatado e reconhecido pelo PS2.

---

- **Downloads reais pela rede** — conexão HTTP de verdade, com barra de progresso, velocidade estimada e tratamento de erro visível na tela (sem travar ou voltar ao menu sem explicação).
- **8 temas visuais** — Escuro, Claro, Azul PS2, Verde Matrix, Roxo, Laranja, Cinza e Vermelho.
- **Sistema de perfil** — nome de usuário, nível, experiência, histórico e lista de jogos recentes.
- **Busca aprimorada** — por texto no título ou por letra inicial.
- **Gerenciador de arquivos embutido** — navegação, copiar, mover, renomear, excluir e criar pastas direto do menu.
- **Aba de notícias** — novidades de cada versão exibidas dentro do próprio app.
- **Configurações expandidas** — drive padrão de instalação, conexões paralelas, exibição de FPS/relógio/memória, e mais.

---

## 📋 Funcionalidades

- **Interface intuitiva** — navegação simples entre jogos e apps.
- **Barra de progresso** — acompanhamento em tempo real do download.
- **Gestão direta** — extração e cópia de arquivos direto para o dispositivo de armazenamento.
- **Segurança** — limite de 10 downloads diários por usuário, para evitar sobrecarga no servidor.
- **Controles rápidos** — suporte a login e atalhos (ex: R1 para sair do aplicativo).

---

## 📥 Como Instalar

1. Baixe a versão mais recente do projeto.
2. Copie a pasta do release para a raiz do seu pendrive ou HD.
3. Abra o **wLaunchELF** (ou seu gerenciador de homebrew preferido) e execute o `.elf` do PSTORE2.

---

## 🎮 Como Utilizar

1. Ao abrir o app, insira seus dados de login e pressione **Triângulo** para confirmar.
2. Navegue pelos títulos usando o direcional.
3. Pressione **X** para iniciar o download do jogo desejado.
4. Ao final do download, pressione **Seta para a Direita** para copiar o arquivo para o seu dispositivo de armazenamento.
